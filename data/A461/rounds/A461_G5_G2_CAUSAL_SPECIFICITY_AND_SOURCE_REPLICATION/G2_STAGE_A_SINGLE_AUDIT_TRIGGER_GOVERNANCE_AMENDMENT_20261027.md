# A461-G5-G2 Stage-A：2026-10-27 独立审计门槛撤销的流程修订

**性质：仅治理/准入流程修订；不是 G5/G2 科学数据修订，也不是 GPU 授权。**  
**上位规则：** [JEV 唯一独立审计触发政策 V2](../../../research_governance/2026-10-27_JEV_SINGLE_TRIGGER_PAPER_CLAIM_AUDIT_POLICY_V2.md)。规范路径为 `research_governance/2026-10-27_JEV_SINGLE_TRIGGER_PAPER_CLAIM_AUDIT_POLICY_V2.md`。

## 已确定的流程替换

针对这项正在推进的研究，原执行计划里“每一版 GPU Runner 必须先独立 L2 PASS”的**纯工程审计**要求，自 2026-10-27 起不再作为默认科研准入门槛；不再提交 V4/V5 的独立工程审核申请，也不再因新真实模型输出而自动启动逐次独立科研审计。

只有当**研究 AI 明确宣称已经完成一套创新性足够、完整成果足以支撑一篇论文的研究**时，才发起**一次针对整篇论文成果**的独立科学审计。

历史审计记录（V2 `L2_REJECT_P0x2_P1x2`、V3 `L2_REJECT_P0x1_P1x2`）**不删、不改、不假装为 PASS**。已发现的问题转由执行 Agent 按实际可达性和实际风险评估，作为正常工程测试与缺陷修复处理，不在本研究阶段持续提交独立审计。

## 科研冻结与执行约束保持不变

- 维持 Option A 的 W31 frozen witness / 124 个场景；manifest blob `01ca53908cc73276d4f6821a4892f05e47e02a15`，roster blob `1bc84bf56b9dd63a77b20b5cf8d105cdfe9af5e8`；**372 primary + 6 replay = 378** 个计划物理前向，**128/128/122** 三批；不得更改 Gold、已选 scene、token SHA、来源独立性和停止标准。
- 真实 GPU 前向目前**仍为 0 次新调用（按现有归档证据）**；本流程修订**不表示用户已批准运行**。必须另行取得用户对任务、模型和 378 次/3 批实际预算的明确批准，自动检查模型/输入/预算和原始留证，所有服务器新文件仅在 `~/wjc`。
- 当前冻结 V3 Runner blob `b78da9c0476f0558cd77fa9771c04d020830dede` 在代码中仍要求 `blind_review_verdict=PASS`，因此**不得直接用 V3 伪造 PASS 去触发 GPU**。要应用新流程，Owner 必须先按普通开发过程修改该门的代码与可执行 admission 格式，改为真实用户 GPU 授权和有效的自动预算/输入检查，形成新 blob + CPU 自动测试与回据；无需提交独立 L2。新 Runner 仍需在真正获用户许可后方能加载模型。
- 本修订仅删除**独立工程审计**的流程要求，不删除实际可执行的停机条件：超预算/未经授权、输入哈希不符、证据写入不可用都应由程序安全拒绝执行，作为正常工程处理。

**执行口令：实现 Agent 自主修复+测试 → 请求用户对真实 GPU 实验明确授权 → 有界执行、留证、研究 AI 自主分析 → 仅当 AI 宣称“完成完整论文级创新成果”才审计一次。**

此文件是对 A461 既有独立 L2 流程的**显式修订**；以前版本所有审计结果、冻结科学数据和运行回执持续有效。
