# A461-G4 G0E：供体资格与机制研究设计备忘录（供盲评；CPU 分析，2026-10-25）

**性质**：G0 准入计划第 5 步的评审输入。本备忘录不批准 GPU；它把供体资格事实、混杂与建议的分级设计摆给独立盲评。

## 1. 供体资格事实（来自冻结队列与 G3 存档）

| 供体类型 | 数量 | 资格判定 |
|---|---:|---|
| 同场景 clean→conflicted 且 C 头识别成功的正供体 | **0** | G3 全部 20 个 T2 处理臂中仅 run-338 识别成功，但其有效 N1B 中性自身假警报 C=true——不满足"valid matched neutral C=false"资格 |
| 严格负供体（clean old、有效配平中性、处理识别失败） | **11** | 冻结 STRICT cohort |
| 既有冲突正上下文（T3） | **6** | 起始状态即 C=true，**非同场景**供体；2 个组与 T2 组重叠 |
| 旧臂假警报（clean 上报 C=true） | **3**（accept 格） | 可作"假警报供体"研究假阳性方向 |

**结论（与冻结协议一致）**：双向语义修复设计（failing←positive donor 与 positive←failing donor）**缺少合格正供体**，不可准入；若强行使用 T3 跨场景供体，只能作诊断性 OOD/同任务正对照，不能证明语义特异的因果拯救。

## 2. 混杂与设计约束（G−1 已登记，此处工程化）

1. **分支相对锚点**：新旧臂 question 分支 token 逐位相同（26/26），但 state 增长 +33/+34 使绝对索引漂移——一切状态侧干预必须用 rows_of 分支内 decide/opts 锚点 + 追加事件 span（首差异定位），禁止绝对索引换序。
2. **混合架构**：Qwen3.5 GatedDeltaNet 混合层不服从朴素 packed block-causal mask；干预必须走 forward_rows_batch 的独立行路径，禁止把循环状态当普通注意力残差流换块。
3. **读出分解非因果**：ΔM 三项分解（query δ、key 对比 δ、交互）是精确代数恒等式，不是中介分析；其解释必须与重建门（分解值 vs 原生 logits ≤FP32 容差）同时报告。
4. **run-338 的特殊性**：唯一识别成功对，但其 N1B 假警报——它是"成功读取"的内部结构样本，不是语义特异性的成功样本。

## 3. 建议的分级设计（供盲评裁决）

**第一级（读出分解，GPU 需求小）**：对 11 严格对 + run-338 + 6 T3 的 old/new/N1B 臂各做一次原生前向，hook 捕获 conflicting_vote 分支的 h_decide 与 h_opts（true/false 两候选端），计算 q/k 投影与 ΔM 三项分解。检验 H_Q/H_K/H_B：识别失败的 margin 变化主要由查询侧（决策标记聚合）、键侧（候选端编码）还是交互承载。预算：26 旧/新对 = 52 臂 + run338 N1B + 4 重放 ≈ 57 次前向（≤128）。

**第二级（探索性跨上下文 patch，GPU 需求中，须盲评通过后另批）**：T3 正上下文 → T2 失败场景的候选端 key 注入（诊断性，非语义特异）；同位 sham、随机 token、无关头对照；报告 off-target Q/action 指标。

**第三级（语义特异双向修复）**：**在获得合格正供体之前不可设计**。可行路径：新构造含"追加后识别成功"场景的确认对（需要新的 CPU 构造轮 + 新 G−1 + 功效计算），或接受本阶段以读出分解 + 负结果探针收尾。
